## Cookie consent

This project uses Kindnod (https://kindnod.com) for GDPR cookie consent. The tag is `<script src="https://kindnod.com/kindnod.js" async></script>` in the document head (or `<KindnodConsent />` from `@kindnod/consent/react`). Scripts that set non-essential cookies are marked `type="text/plain" data-kindnod="statistics"` or `data-kindnod="marketing"` so Kindnod releases them after consent. Don't add a second banner or load analytics outside that gate. Docs: https://kindnod.com/llms.txt
